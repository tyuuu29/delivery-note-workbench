# 送货单批量提取工作台

多供应商送货单智能提取工具。纯前端单文件应用，无需安装、无需后端：打开网页即可使用。

**在线地址：https://delivery-note-workbench-eiw.pages.dev**

## 功能

- 批量上传送货单（图片 / PDF），自动识别并提取表格数据
- 多供应商别名与字段映射规则，可自定义并保存在本地
- 提取结果可导出为表格文件

## 使用

1. 打开在线地址（或本地直接双击 `index.html`）
2. 首次使用需在设置中填入自己的大模型 API Key（阿里云百炼 DashScope）
3. 上传送货单，等待识别完成，检查结果后导出

## 隐私说明

- 全部逻辑运行在浏览器本地，**没有服务端**
- API Key 与识别数据仅保存在你当前浏览器的 `localStorage`，不会上传到任何第三方服务器
- API Key 只发往你自己配置的大模型接口地址

## 部署

站点为单个静态文件，通过 Cloudflare Pages 托管。根目录的 `index.html` 即入口页面。

```bash
git push
```

推送到主分支后由 Cloudflare Pages 自动构建发布。

## 本地开发

无需构建步骤。修改 `index.html` 后在浏览器刷新即可预览。
